BSE File Sync

A personal study-file utility maintained by makomat17. It is being developed to copy attachments from three selected Google Classroom courses into the owner's existing local study folders.

Purpose and access

The selected courses are International Trade, Foundations of Data Science and QSM I. The utility uses Google's official Classroom and Drive APIs with the owner's consent and read-only permissions. It is designed to preserve existing files and save updated attachments as separate versions.

Google access is used to identify the account, find the selected courses, read their topics and attachment metadata, and download accessible course attachments. The utility does not request permission to change Google Classroom or Google Drive content.

Local operation

The planned daily sync runs on the owner's Windows computer. New files are intended to be classified using Codex, with filenames, course context, folder structure and content excerpts where needed. The destination is inside the owner's OneDrive folder, so OneDrive may also store copies in the cloud. See the privacy policy for details.

This is a personal utility, not an official product of Barcelona School of Economics or Google. This website provides information only; it does not offer a public sign-in or distribute course materials.
